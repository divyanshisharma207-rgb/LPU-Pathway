# LPU Pathway – Accessible Campus Navigation

LPU Pathway is a step-free and accessible indoor-outdoor campus navigation web application designed for students and visitors, with special focus on wheelchair users and visually impaired individuals at Lovely Professional University.

## Features

- **Interactive Campus Map**: Outdoor map powered by Leaflet.js with building markers, accessible paths, ramps, and lifts.
- **Indoor Floor Plans**: Floor-by-floor guides for campus blocks (Ground to upper floors).
- **Route Planner**:
  - **Fastest Route**: Shortest direct path.
  - **Step-Free Route**: Wheelchair-friendly routing avoiding stairs, utilizing ramps and lifts.
- **Audio Directions (Text-to-Speech)**: Read route instructions aloud.
- **Accessibility Barrier Reporting**: Community reporting for broken lifts, blocked ramps, or damaged tactile paths.
- **WCAG 2.1 AA Compliant**: High-contrast support, screen reader compatibility (TalkBack & VoiceOver), keyboard navigation, and responsive mobile-first design.

## Getting Started

Simply open `index.html` in any modern web browser or deploy directly using **GitHub Pages**.
