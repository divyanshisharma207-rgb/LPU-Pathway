Help & Accessibility Guide

Using with TalkBack (Android)

  • Swipe right/left to navigate between controls
  • Double-tap to activate buttons and links
  • Use the route form then swipe down to hear directions
  • Tap "Read Aloud" button to hear the full route
  • All map features have text alternatives

Using with VoiceOver (iOS/Mac)

  • Swipe right to move forward through elements
  • Double-tap anywhere to activate focused item
  • Use the Rotor (two-finger rotation) for headings
  • Use the "Read Aloud" button for spoken directions
  • Live regions announce route updates automatically

Keyboard Navigation

  • Tab — Move to next interactive element
  • Shift + Tab — Move to previous element
  • Enter / Space — Activate buttons
  • Arrow keys — Navigate radio button options
  • Skip links at the top take you to main areas

Step-Free Route Guide

  • Always choose "Step-Free" if you use a wheelchair
  • Routes use ramps and lifts only — zero stairs
  • If a lift is broken, the route auto-updates
  • Accessible routes may be slightly longer in distance
  • Report a blocked ramp or lift using the Report tab

Campus Accessibility Support

  • Disability Support Cell: +91-1824-404040
  • Campus Helpline: 1800-102-4431
  • Email: accessibility@lpu.in
  • Hours: Mon–Sat, 8:00 AM – 6:00 PM
  • Emergency assistance is available 24/7 at the security desk

Display Settings

  • Use the A+ button in the header to increase text size
  • High-contrast mode respects your OS settings
  • All colour is backed by icons and text labels
  • Zoom up to 400% with no content loss
  • Works with browser font size settings
